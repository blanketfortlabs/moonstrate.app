# moonstrate.app

The product site for [Moonstrate](https://moonstrate.app), a private period and cycle tracker by
Blanket Fort Labs LLC. Served by GitHub Pages from this repo.

This repo holds the **built output only**. The source (page fragments, the stylesheet, and the
build script that derives the Learn pages from the app's own education content) lives in the app
repo under `site/moonstrate/`. Edit there, run `python3 site/moonstrate/build.py`, and copy
`public/` here.

No build tooling, no scripts, no third-party requests. Fonts are self-hosted: Kaushan Script is
licensed under the SIL Open Font License 1.1.

Copy rules that bind here as much as in the app: inclusive language, never weight/BMI/calorie
framing, never lunar-causation claims for the "inner seasons" metaphor, and not medical advice.
